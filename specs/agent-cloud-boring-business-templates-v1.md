# Agent Cloud Boring Business Templates v1

## Outcome

Turn twelve proven, simple internet-business patterns into novice-friendly agent templates that configure a useful outcome instead of asking users to design an agent architecture.

## Product contract

- Every card names the buyer, result, revenue mechanic, core loop, required inputs, and integrations.
- Selection follows a five-ingredient flow: business, demand, work, memory, and safety.
- Standard templates use bounded run memory and approval rails.
- Premium templates visibly include governed long-term memory, provenance, and higher-liability trust controls.
- Applying a template updates the editable AgentSpec defaults; it never launches, spends, connects credentials, or publishes automatically.
- B2B, B2C, and C2C filters remain understandable on mobile and keyboard accessible.

## Template set

Qualified Match Board, Booked Job Concierge, Personal Briefing, Outcome Generator, Citable Comparison Lab, Autonomous Micro Utility, Books Close Assistant, Adaptive Exam Coach, Community Memory Guide, Certified Domain Transcript, Career Concierge, and Calendar Yield Manager.

## Proof gates

- Exactly 12 unique template IDs.
- Every template has 3–5 loop stages, at least one input, one integration, explicit tier, memory mode, authority mode, and budget.
- UI test applies a template without triggering a mutation.
- Responsive design has no horizontal overflow at 390px.

Release status and technical limits

The released baseline reviewed here is core 0.49.7. Core 0.50.0 and plugins 1.3.6 are publication targets after merge, not a claim of current availability. PR 354 adds the bounded Proof Agent, signed execution-observation checks and Devin evidence profile.

The Proof Agent runs a human-approved signed plan and records evidence for review. It does not approve its result. Signed-observation checks establish the declared observation binding, not code correctness or release readiness. Local tests do not establish marketplace availability or live provider compatibility.

Audit depth depends on language, project policy and supplied evidence. The security scanner inspects Python ASTs; static inventory is not runtime proof. This is a static preview, not a hosted repository scanner.

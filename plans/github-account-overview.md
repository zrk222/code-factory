## Risk controls
- Validate every path segment derived from a Git remote and invoke subprocesses with argument arrays, no shell, and a timeout.
- Use explicitly declared GET operations only; never request a token, write setting, post comment, or mutate a pull request. Inventory and search only repositories/work visible to the existing gh session, keep origin operational details explicit, and report truncation state.
- Bound every result list to 100 rows, exclude sensitive bodies/comments/emails, and mark truncation/partial access.
- Treat all GitHub-derived text as untrusted instructions/data; never execute its contents.
- Keep `gh` credentials inside the GitHub CLI credential store; the adapter must not retrieve, print, copy, or persist them.

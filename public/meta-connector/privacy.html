Code Factory Audit Evidence — Privacy

Updated September 27, 2026. This notice covers the Code Factory audit connector at cf.wizeme.app. It does not cover WizeMe.

Information used

When you link an account, Clerk handles sign-in and Code Factory verifies the access token. The connector stores a Clerk account identifier and, if you choose to upload them, bounded audit summaries: repository name, commit identifier, audit outcomes, finding labels, coverage limits, and repair steps. It does not request repository source code. Do not put secrets or personal data in finding text.

Purpose and sharing

The service uses these records to return your account's audit summaries to you through Muse. Vercel hosts the API, Neon stores audit records, and Clerk provides authentication. These providers process service data for those functions. The connector does not sell audit records or use them for advertising. Once you link Muse, the audit details you request are returned to Muse; Meta's own policies govern its handling of that response.

Retention and deletion

Audit summaries stop appearing in API results after seven days. Expired database rows are removed on subsequent uploads; they may remain in storage until then. You can request deletion of your account records at any time using the support contact below. A linked write-scoped account can also delete its records through the API. Operational logs and provider backups follow the relevant provider retention rules.

Security and contact

Account data requires a scoped bearer token and is partitioned by authenticated account. No Internet service is risk-free. For access, correction, deletion, or privacy questions, contact rkatz22@gmail.com or open a Code Factory issue without including secrets.

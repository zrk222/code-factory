# Agent Oven visual contract

The interface uses an industrial editorial language: warm paper, carbon-black machinery, safety orange, stamped evidence, precise monospace metadata, and generous whitespace. It must feel like a calm control room rather than a generic gradient dashboard.

The primary decision point always places budget, authority, and evidence status adjacent to the action. Prototype receipts are visibly labeled unsigned. Loading, empty, blocked, and completed states receive designed treatments.

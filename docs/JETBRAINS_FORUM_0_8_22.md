# FactoryLine 0.8.22 — paste-ready JetBrains update

An agent told me the work was done. The missing question was: did its workflow
stay inside the task while it got there?

FactoryLine 0.8.22 adds an Atomic Proof Adapter to Unified Graph Ops. It checks
the supplied stage graph, scoped handoffs, checkpoint continuity, exact source
bytes, resume lineage, and the sealed Oracle Contract—then shows where the
story diverged.

This is useful after Junie, Copilot, Claude Code, Codex, or another orchestrated
agent run. FactoryLine does not replace those tools or run their workflow. It
is the independent, local proof layer before a human approves the result.

The update is free and local-first. Try it on a real agent handoff and share
the first drift it catches:
https://plugins.jetbrains.com/plugin/33009-factoryline-ai-proof

# Code Factory Public Positioning

Use this copy as the source of truth for public Code Factory surfaces. It leads
with one testable outcome, separates the audiences by job, and keeps the
authority boundary visible. It is product copy, not a measurement or a release
receipt.

## Core promise

> **Catch AI-generated tests that could never fail — before review.**

**Free, local proof for code built with AI.** Start with an outcome, a fuzzy
specification, or a risky diff. Code Factory binds the declared intent,
challenges whether a test can actually reject the failure it claims to cover,
and shows the current evidence gap plus the next human decision.

## Audience value

| Audience | Plain-language value | First action |
| --- | --- | --- |
| Vibe coder | Turn an outcome into a contained MVP, then see what is still unproven before calling it done. | `factory mvp "Build an approval tracker" --root .` |
| Senior developer | Challenge a passing test, inspect the exact changed scope, and leave a local receipt another reviewer can check. | `factory change review --root . --json` |
| Team or enterprise | Keep AI work in approved scope, preserve named human decisions, and use expiry-bound evidence for supervision without giving Code Factory merge or release power. | `factory graph ops --root . --json` |

## Authority and privacy boundary

Code Factory is local-first: the core workflow needs no account, model key, or
source upload. It does not silently call a model or decide to repair, approve,
merge, publish, deploy, sign, send a message, or use credentials. A receipt is
evidence for the supplied local inputs and checks—not a production-readiness,
security, performance, cost, token, productivity, or release claim.

## Visual rule

Use only verified current product captures and the completed 90-second
**Proof of Survival** film. The film is release media only after its composite
passes visual checks and its final rendered file is independently inspected.
Never substitute concept art, a stale UI capture, a queued workflow, or an
unverified metric for product evidence.

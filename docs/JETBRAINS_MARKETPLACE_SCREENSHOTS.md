# JetBrains Marketplace Screenshot Brief

Use real plugin UI, not concept art. Capture the default JetBrains light theme at
1280x800 (16:10) or larger with a sample repository that contains no private data.

1. **Run your first proof** - FactoryLine tool window with `Run first proof` as
   the first control and a successful, redacted doctor result.
2. **See what changed** - `Analyze changed proof` output showing which local proof
   is affected by the current diff.
3. **Inspect receipts** - a local receipt with status and requirement evidence.
4. **Measure savings honestly** - the paired savings report with measured values
   and unavailable fields visibly distinguished.
5. **Work across JetBrains IDEs** - one clean compatibility image naming only IDEs
   verified by the release workflow.

Do not show old version numbers, install counts, projected savings, invented
ratings, or unsupported performance claims. Re-capture any screenshot when its
visible UI or factual content changes. Recommended captions are outcome-led and
under 80 characters.

## Existing real product-tour assets

`docs/assets/marketplace/factory-studio-mvp-1280x800.png` and
`docs/assets/marketplace/graph-ops-studio-1280x800.png` are verified captures
from the Factory Studio web surface. They support the README, PyPI rendering, and
the public landing page only. They do **not** satisfy Marketplace media criteria:
the Marketplace set must show the relevant JetBrains product interface and must
not contain a browser window. Treat this distinction as a release gate, not a
captioning preference.

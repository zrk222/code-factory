# Code Factory 0.24.1

Code Factory 0.24.1 publishes the Marketplace acquisition assets and public
measurement boundary introduced after 0.24.0's Unified Graph Ops release.

- The Marketplace Acquisition Kit supplies accurate listing copy, a two-minute
  activation path, relevant tags, and a strict IDE-native screenshot brief.
- The README and public landing page now show real local Factory Studio and
  Graph Ops captures. They are product-tour assets, not JetBrains IDE media.
- `python scripts/jetbrains_marketplace_measurement.py --json` reports only the
  public download delta from its checked-in baseline; conversion and causal
  uplift remain unknown without Marketplace analytics.
- The new [Code Factory overview](OVERVIEW.md) explains the novice MVP path,
  Graph Ops, proof reuse, and supervised team boundaries in one page.

The PyPI package, GitHub release, and Hugging Face public surface receive this
same release state. JetBrains Marketplace publication remains independently
blocked while its prior update is pending review.

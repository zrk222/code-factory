# Code Factory 0.24.2

Code Factory 0.24.2 makes the free, local-first workflow easier to discover
without weakening its authority boundaries.

- The VS Code and JetBrains integrations can offer one optional **Star Code
  Factory** action after a successful local command. The repository opens only
  if the user clicks; no source, receipt, telemetry, or browser action is sent
  automatically.
- Generated output maps include optional copyable attribution. Code Factory
  does not post it, edit other files, or send output data.
- The public GitHub, PyPI, editor, Hugging Face, and community-launch surfaces
  now lead with an outcome-first MVP path, exact proof boundary, and Unified
  Graph Ops visibility.
- JetBrains binary verification is repaired by removing a forbidden internal
  API from the opt-in star prompt.

The Python package and GitHub release publish this source state. The Open VSX
workflow can publish the sealed VSIX only when its protected environment has a
publisher token. JetBrains Marketplace publication remains separately blocked
while its preceding metadata update is under Marketplace review.

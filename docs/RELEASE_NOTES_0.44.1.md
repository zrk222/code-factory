# Code Factory 0.44.1 — Current visuals and transparent outcomes

This patch makes the public product surfaces match the current Code Factory
experience and adds one bounded, inspectable example of expected outcomes.

## What changed

- GitHub, Hugging Face, Zenodo metadata, and the VS Code/Open VSX adapter now
  use the current Code Factory product story and visuals.
- The VS Code/Open VSX adapter advances to 0.8.11 and explains expected outcomes
  for vibe coders, engineers, teams, and enterprises.
- A 60-day personal-use case separates observed local Codex activity from a
  counterfactual capacity model: 25 related tasks, 133 completed turns, 2,710
  command runs, 785 MCP or app calls, and 555 file-change events were observed.
- The model estimates 30–110 gross manual-equivalent hours over 60 days after a
  50% overlap haircut, or 15–55 hours per month. At an illustrative loaded rate
  of $75–$150/hour, modeled gross capacity value is $2,250–$16,500.

## Boundary

This is one user's case, not a benchmark, guaranteed ROI, or verified cash
saving. Net savings must subtract tool cost and human oversight. First Proof
remains a demonstration, not a production, security, coverage, identity, or
release certificate.

# Proof Clinic: ten real repositories

Code Factory is inviting maintainers of up to **ten real repositories** to run
one supervised proof review. Enrollment is voluntary and is not claimed until a
repository owner opts in publicly.

## What owners receive

- A bounded first-proof walkthrough and one project-specific proof target.
- A local receipt showing whether the declared check could reject its failure.
- A privacy-safe Proof Card the owner may share, keep private, or delete.
- A concise report of a verified result, hollow check, or exact blocker.

## Safety boundary

- Source stays local by default; no private repository access is requested.
- The repository owner chooses and runs every project command.
- Code Factory does not merge, deploy, publish, or store credentials.
- Quotes, logos, case studies, and public cards require separate written owner
  approval. Participation is never exchanged for a positive rating or review.

Open a GitHub issue titled `Proof Clinic: <repository>` with the language,
current test command, and the behavior you most need the test to reject. Do not
include secrets or private source.

# Precision-tier protocol draft

The three prototype scripts are preserved at the original proposal commit. The draft describes the hypotheses and input pins. Its executable protocol still requires exact changed-file membership, full alert spans, packet-bound arm and tier labels, and independently verified source and sink binding for corroboration.

The recall harness's `review-alerts` command already checks the score receipt, source captures, changed-file population, and retained finding spans. A qualified labeling workflow can take that export as its input.

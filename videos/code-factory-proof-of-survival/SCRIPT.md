## Line 1 — The question (Frame 1)

**Time:** 0.0 – 9.0s
**Delivery:** Direct. Leave a beat before the final question.

    AI coding is fast. The expensive part is finding out whether a passing test could ever have failed.

## Line 2 — The proof lane (Frame 2)

**Time:** 9.0 – 18.0s
**Delivery:** Calmly introduce the category.

    Code Factory is a local-first proof lane for AI-assisted software delivery. It turns a fast idea into work a human can actually inspect.

## Line 3 — Vibe coding (Frame 3)

**Time:** 18.0 – 28.0s
**Delivery:** More energetic, practical.

    For vibe coders, that means you can begin with a plain outcome, lock the intent, build an MVP, and see what the tests really prove before you call it done.

## Line 4 — The gauntlet (Frame 4)

**Time:** 28.0 – 39.0s
**Delivery:** Precise; give “cannot actually fail” weight.

    When generated code needs a harder question, the Survival Gauntlet runs declared scenarios against the real command you choose. It can expose a test that looks green but cannot actually fail.

## Line 5 — Honest outcomes (Frame 5)

**Time:** 39.0 – 50.0s
**Delivery:** Deliberate, clear distinctions.

    The result is not a vague AI grade. It is a survival card: survived, hollow, or blocked, with the command, evidence, and next action visible.

## Line 6 — Senior and team control (Frame 6)

**Time:** 50.0 – 61.0s
**Delivery:** Practical, enterprise-grade without jargon.

    For senior engineers and teams, Code Factory adds deterministic checks, named approvals, proof deltas after a change, and bounded repair authority. The code path stays reviewable from intent to evidence.

## Line 7 — Graph Ops (Frame 7)

**Time:** 61.0 – 72.0s
**Delivery:** Let the operational view feel tangible.

    Graph Ops makes that operational picture visible: current proofs, stale work, blocked gates, ownership, and the exact next safe action, all in one local control surface.

## Line 8 — Optional continuity (Frame 8)

**Time:** 72.0 – 81.0s
**Delivery:** Reassuring and explicit about privacy.

    Optional continuity carries forward only verified, purpose-scoped evidence references. It does not turn private project memory into proof, and it never replaces human judgment.

## Line 9 — Close (Frame 9)

**Time:** 81.0 – 90.0s
**Delivery:** Warm, concise finish.

    Build quickly. Verify honestly. Keep control. Code Factory is open source and local first, for anyone tired of discovering the truth after the demo.

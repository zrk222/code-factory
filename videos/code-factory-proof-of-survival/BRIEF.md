## Intent

Create a 90-second, professional, high-energy but credible Code Factory launch film. It should show a visual software factory in motion, then make the distinction clear: solo builders can turn a quick idea into an MVP with a proof lane, while senior engineers and teams gain explicit evidence, named approvals, controlled repair, and a clear operational record. The message is evidence-first engineering, not autonomous deployment or unmeasured productivity claims.

- Use a Deepgram TTS voice for the narration, with a neutral, precise, confident delivery.

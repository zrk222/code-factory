## Video direction

Visual thesis: a precise software factory after dark — warm editorial craft meets an operational control room. Use the adopted `code-editorial` frame system, with the verified dark canvas, mint accent, Inter display/body, and JetBrains Mono operational labels. Treat product screenshots as evidence plates, never decoration. The Remotion factory animation is the visual spine; authentic local UI plates enter only when the narration names their function.

Motion grammar: smooth `power3` long-tail settles, one decisive camera push in each early beat, then held reading moments. Sequentially reveal only the next proof object named by narration. Use short velocity-matched cuts between frames; reserve mint for verified work and coral/orange only for hollow or blocked states. Keep the bottom 17 percent clear for captions. No endless loops, bouncy entrances, fake dashboards, fake metrics, scrolling code walls, floating-card soup, noisy particles, or production-readiness claims.
